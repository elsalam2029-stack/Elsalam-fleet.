# نظام السلام لإدارة الأسطول — بداية الخادم API

هذه حزمة بداية محلية للانتقال من نموذج `localStorage` إلى API وخادم PostgreSQL. **ليست منشورة ولا تعتبر جاهزة للإنتاج**، ولم تُربط بعد بمستودع GitHub أو قاعدة بيانات مستضافة.

## الموجود الآن
- Node.js + Express API.
- فحص صحة الخادم وقاعدة البيانات: `GET /api/health`.
- جلسات محفوظة في PostgreSQL مع cookie من نوع HttpOnly وSameSite.
- تسجيل دخول مبدئي بكلمات مرور Argon2id، وتحديد محاولات الدخول وقفل مؤقت.
- `GET /api/auth/me` و`POST /api/auth/logout`.
- لا توجد نقاط CRUD للسيارات/السائقين/الرحلات/الوقود حتى يتم تطبيق فحص الصلاحيات لكل مسار.

## تشغيل محلي للاختبار فقط
1. جهّز PostgreSQL جديدًا، وراجع نسخة احتياطية أولًا.
2. نفّذ `alsalam_fleet_schema.sql` ثم `alsalam_fleet_seed.sql` من ملفات المشروع الأصلية، مرة واحدة فقط لكل قاعدة جديدة.
3. انسخ `.env.example` إلى `.env` واضبط `DATABASE_URL` و`SESSION_SECRET` عشوائيًا بطول 32 حرفًا على الأقل.
4. ثبّت Node.js 20 أو أحدث، ثم:
   ```bash
   npm install
   npm run check
   npm start
   ```
5. افتح `GET http://localhost:3000/api/health` محليًا. لا توجد حسابات دخول افتراضية. يجب إنشاء حساب مسؤول عبر مسار إعداد آمن قبل استخدام تسجيل الدخول؛ لم يُضف هذا المسار بعد.

## قبل النشر
- إضافة عملية إعداد أول مدير آمنة ومؤقتة، ثم تغيير كلمة المرور عند أول دخول.
- إضافة فحص صلاحيات على الخادم حسب الدور، وتدقيق التغييرات.
- إضافة حماية CSRF عند استخدام الجلسات مع واجهة المتصفح، وCORS مقيد إذا كانت الواجهة على أصل مختلف.
- ضبط HTTPS و`TRUST_PROXY` حسب مزود الاستضافة.
- إضافة MFA/TOTP مشفر بمفتاح خارج قاعدة البيانات.
- إضافة API للسيارات والسائقين والرحلات والوقود والإضافي والتقارير، مع اختبارات.
- تنفيذ ترحيل البيانات الحالية على قاعدة اختبار أولًا، ومقارنة أعداد السجلات، وعدم دمج أو حذف التكرارات تلقائيًا.
- ضبط النسخ الاحتياطي المنفصل المشفر واختبار الاستعادة.
- إضافة أسرار الإنتاج من لوحة الاستضافة فقط، وعدم وضع `.env` أو كلمات المرور في GitHub.

## ملفات المخطط والبيانات
ضع `alsalam_fleet_schema.sql` و`alsalam_fleet_seed.sql` الأصليين بجوار هذا المجلد عند إعداد قاعدة اختبار. لم تُنسخ بيانات الإنتاج أو تُرحّل في هذه الخطوة.
